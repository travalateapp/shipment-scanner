# Travalate Daily Task Sheet (Google Apps Script)

Daily task sheet per department: To do / In progress / Complete, subtasks, deadlines, calendar, dashboard,
inbox messages, employee logins (email + password, stored hashed) and admin settings. `doPost` also serves a
separate Windows desktop agent (screenshots during working hours for employees marked "Monitored"); that agent's
code is not in this repo yet.

| File in Apps Script | File here |
|---|---|
| `Code.gs` (everything combined in one file) | `Code.gs` |
| HTML file `Index` | `Index.html` |

`emergencyResetMyPassword()` has its password written as `XXXX` here. Only type a real one in the Apps Script
editor when you need to run it, then remove it again.
