# PO Web App with Vendor Autofill (Google Apps Script)

Purchase orders as PDFs (Vertex42 layout). The first PO for a vendor saves the vendor and its items and rates; after
that, picking the vendor fills everything in. Screens: New PO, Vendors, History. Optional App PIN (Settings tab).
Setup steps are at the top of `Code.gs`.
